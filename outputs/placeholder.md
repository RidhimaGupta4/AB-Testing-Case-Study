# outputs/

This folder contains all 7 publication-quality charts generated by `scripts/03_charts.py`.

## Files generated on first run

| File | Description |
|---|---|
| `01_primary_results_summary.png` | Conversion rate, RPV, and bounce rate side-by-side |
| `02_cumulative_conversion_rate.png` | Day-by-day cumulative CR for both groups |
| `03_confidence_intervals.png` | 95% CI plot across all metrics |
| `04_segmentation_analysis.png` | Lift by device, user type, and category |
| `05_power_analysis_curve.png` | Power vs sample size for three MDE levels |
| `06_revenue_distribution.png` | Order value distribution and daily RPV |
| `07_business_impact.png` | 12-month revenue uplift projection and scenario range |

## How to generate

```bash
python scripts/03_charts.py
```
